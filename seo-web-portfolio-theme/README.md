# SEO Specialist & Web Developer Portfolio

Static multi-page portfolio theme designed for GitHub Pages.

## Pages
- Home
- About
- Projects
- Contact
- 4 sample case studies
- 404 page

## Setup
1. Replace placeholder name, email, LinkedIn and GitHub links.
2. Add your CV at `assets/documents/cv.pdf`.
3. Replace sample project content and results.
4. Push the folder contents to a GitHub repository.
5. Enable GitHub Pages from the `main` branch and `/root`.

## Important
Do not publish unverified SEO metrics. Replace all sample data with real, explainable results.
